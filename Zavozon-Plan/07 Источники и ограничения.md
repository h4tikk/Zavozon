## Пределы уверенности

Не проверены живая БД, применённость последней миграции, работоспособность очереди, конфигурация реального бота, доступность внешнего Minecraft JSON, реальная экономика тарифов и UI frontend. Эти пункты явно превращены в задачи/решения. Не выводить из schema успешный запуск production.

Исторический контекст использован только для последовательности ранее обсуждавшегося Rails/Telegram дизайна. Текущие выводы о моделях получены повторным чтением checkout 2026-10-20.
