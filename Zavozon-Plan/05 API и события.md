## Матрица уведомлений

| Событие | Получатель | Когда создавать | Действие |
| --- | --- | --- | --- |
| Покупка создана | Покупатель | Commit checkout | Инструкция оплаты/открыть покупку |
| Claim submitted | Ревьюер/разрешённая группа | Commit ReviewRequest | Рассмотреть конкретную версию |
| Оплата принята | Покупатель и продавцы своих Order | Commit подтверждения оплаты | Продавцу принять заказ |
| Оплата отклонена | Покупатель | Commit решения | Причина/новая попытка |
| Готово к забору | Подходящие approved/available курьеры | Commit ready_for_courier | Взять свободный Order |
| Курьер назначен/забрал | Продавец; покупатель по значимому этапу | Commit перехода | Только актуальная информация |
| Курьер заявил прибытие | Владелец нужного ПВЗ | Commit declare arrival | Подтвердить приём |
| ПВЗ принял и готов выдать | Покупатель | Commit ready_for_pick_up | Получение конкретной посылки |
| Начислен доход | Получатели долей | Commit settlement | Сумма, источник, баланс |
| Вывод подан | Заявитель и уполномоченный ревьюер | Commit reserve/review | Сумма и решение |
| Вывод completed/rejected | Владелец Wallet | Commit результата | Результат/причина |
| Вывод needs_reconciliation | Оператор выплат; заявителю безопасный статус | Commit неопределённого исхода | Ручной разбор, не повторить перевод |
| Профиль рассмотрен | Заявитель | Commit решения | Причина/дальнейший шаг |
| Доступ магазина истекает | Продавец | Одно событие на срок/порог | Инструкция продления |
| Minecraft check/review | Владелец заявки | Commit актуального результата | Статус/доказательство при необходимости |

Сообщение не даёт полномочий. Каждое нажатие заново проверяет actor, владельца, актуальный статус и версию. Старые сообщения можно отредактировать/снять кнопки best effort, но безопасность не зависит от успеха редактирования.

## Приватность и ошибки

Кандидатам-курьерам выдавать только минимальные сведения о маршруте и вознаграждении, не контакты/скриншоты покупателя. Подробности открываются назначенному участнику по политике.

Ошибки API: JSON error.code/message/request_id, 401/403/404/409/422/503 и 500 без внутренних подробностей. Идемпотентный повтор возвращает прежний результат; тот же ключ с другим содержимым — 409. Callback отвечает коротким безопасным текстом через answerCallbackQuery. Job не пытается ответить в уже завершённый HTTP-запрос.
