# M14 Wallet

## Что есть сейчас

Балансов пока нет.

Основание: `Новая модель; отсутствует в app/models и db/schema.rb`. Это статическое чтение исходников/schema, не проверка живой базы.

## Что изменить

- Один кошелёк на User; доход всех его ролей собирается вместе.
- balance включает резерв; доступно = balance − reserved_balance.
- Остатки материализованы для быстрых проверок и сверяются с WalletEntry.
- В первой версии кошелёк только для дохода и вывода; покупка из кошелька не добавляется без отдельного сценария.

## Поля и ограничения базы

- user_id UNIQUE NOT NULL FK.
- balance и reserved_balance bigint NOT NULL DEFAULT 0.
- CHECK balance >= 0, reserved_balance >= 0, reserved_balance <= balance.

## Инварианты и границы

- Создание кошелька и backfill существующих пользователей идемпотентны.
- Баланс нельзя менять обычным обновлением профиля.
- Все изменения только через транзакцию с журналом; удаление с историей запрещено.
