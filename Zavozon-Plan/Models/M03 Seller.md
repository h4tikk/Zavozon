# M03 Seller

## Что есть сейчас

Enum approval_status уже явный: 3 означает suspended. description и reviewer_id уже исправлены в схеме. Остались refection_reason, user.blocked и approved без вопросительных знаков.

Основание: `app/models/seller.rb; db/schema.rb:155–168`. Это статическое чтение исходников/schema, не проверка живой базы.

## Что изменить

- Исправить проверки can_trade и опечатку причины отказа.
- Сохранить paid_until; отдельная модель подписки не нужна.
- Добавить историю ReviewRequest, затем убрать legacy reviewer_id/reviewed_at/rejection_reason.
- Одобренный профиль и действующая оплата нужны для новых продаж; прежние заказы остаются исполнимыми по отдельным правилам.

## Поля и ограничения базы

- UNIQUE user_id после разбора дубликатов.
- Сохранить числовые значения enum, особенно suspended = 3.
- Не удалять legacy-поля до переноса проверенных решений.

## Инварианты и границы

- Один профиль на пользователя.
- Изменение магазина в процессе ревью не подменяет согласованный снимок.
- Удаление профиля не стирает товары и заказы с историей.
