# M05 PickUpPoint

## Что есть сейчас

Nullable reviewer и default статуса уже есть. Enum передаёт имя без двоеточия, условие if: rejected не использует predicate. Координаты уже проверяются как целые.

Основание: `app/models/pick_up_point.rb; db/schema.rb:111–127`. Это статическое чтение исходников/schema, не проверка живой базы.

## Что изменить

- Исправить enum и условие отказа.
- Сохранить owner_id, возможность нескольких ПВЗ у одного User и отрицательные координаты.
- Вынести решение в ReviewRequest; suspension_reason оставить причиной текущей приостановки.
- Хранить снимок адреса/координат и получателя вознаграждения у заказа, чтобы смена ПВЗ не меняла историю.

## Поля и ограничения базы

- owner_id FK обязателен; уникальность owner_id не добавлять.
- pick_up_point_status 0 pending_review / 1 active / 2 rejected / 3 suspended / 4 closed сохранить.
- Legacy reviewer-поля удалить только после переноса.

## Инварианты и границы

- Новые покупки идут только в active ПВЗ.
- Закрытие не отменяет автоматически уже принятые посылки.
- Физический приём и выдача подтверждаются по отдельным переходам Order.
