# M02 ApiSession

## Что есть сейчас

Модель проверяет отсутствующее поле token. Scope active одновременно требует expires_at NULL и expires_at > now, поэтому не выбирает действующие сессии. Digest и срок nullable, уникального индекса digest нет.

Основание: `app/models/api_session.rb; db/schema.rb:17–25`. Это статическое чтение исходников/schema, не проверка живой базы.

## Что изменить

- Проверять token_digest вместо token.
- Действующая сессия: revoked_at отсутствует и expires_at в будущем.
- Сохранять только хеш случайного токена, никогда сырой токен.
- Добавить привязку к User и явный отзыв одной/всех сессий.

## Поля и ограничения базы

- token_digest string UNIQUE NOT NULL.
- expires_at datetime NOT NULL; revoked_at nullable.
- Индекс для очистки по expires_at; существующие некорректные сессии отозвать безопасным способом.

## Инварианты и границы

- Просроченная, отозванная и принадлежащая заблокированному User сессии не дают доступ.
- Переход от старых сессий не должен оставлять бессрочные NULL-сессии.
