# US05 Пункт выдачи

Как **владелец ПВЗ**, я хочу **подать пункт и видеть его заказы**, чтобы **принимать доставки и получать своё вознаграждение**.

## Критерии приёмки

- Один User владеет несколькими ПВЗ; чужие пункты недоступны для изменения.
- Закрытие пункта запрещает новые покупки, но сохраняет обработку прежних.
- Получатель исторического дохода фиксируется и не меняется при смене владельца.
