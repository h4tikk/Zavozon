# US14 Вывод средств

Как **владелец кошелька**, я хочу **запросить вывод на подтверждённый игровой аккаунт**, чтобы **получить доступный доход без повторного списания**.

## Критерии приёмки

- Сумма резервируется при создании заявки, а не при одобрении.
- Одобрение отделено от фактической выплаты; результат с неизвестным исходом не освобождает резерв.
- Отказ освобождает резерв один раз; повторное подтверждение не списывает сумму повторно.
