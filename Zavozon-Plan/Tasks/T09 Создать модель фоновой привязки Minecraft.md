# T09 Создать модель фоновой привязки Minecraft

## Результат

Записывать асинхронный результат без ложного подтверждения владения.

## Пользовательские истории

[[US17 Привязка Minecraft]]

## Модели

[[M18 MinecraftLinkRequest]], [[M01 User]]

## Зависимости

- [[T02 Подготовить User и ApiSession]]
- [[D02 Утвердить подтверждение Minecraft и получателя вывода]]

## Работа

- Presence status и актуальность заявки, нормализованный ник и доказательство ревью.
- Связь с ReviewRequest для ручного подтверждения и с User для итоговой привязки.
- Настроить уникальность подтверждённых ников и сброс подтверждения при смене.

## Предлагаемые сервисы

На этой карточке сервисы не реализуются; см. связанные карточки.

## Входные точки

Внутренние изменения схемы/моделей либо фиксация правил; отдельный публичный endpoint не требуется.

## Готово, когда

- [ ] Онлайн не устанавливает minecraft_verified_at.
- [ ] Старая задача не перезаписывает новую заявку.
- [ ] Параллельное подтверждение одного ника двум User запрещено.

## Проверка

Проверять наблюдаемое поведение и ограничения БД, а не только наличие методов. Для рискованных операций обязательны rollback, повтор запроса и гонка. Набор сценариев: [[06 Проверка и готовность]].

Карточка описывает будущую работу. Наличие похожих полей в исходниках не означает, что задача выполнена.
