## Работа

- Исправленные fixtures и реальные PostgreSQL integration tests; concurrency не проверять только последовательными mocks.
- Double checkout последнего товара; double courier take; approve/reject; approve/expiry; два payment claims.
- Double settlement, concurrent withdrawals, repeated complete и неизвестный внешний перевод.
- Webhook retry, worker crash/lease recovery, Telegram 429/403/timeout и приватность evidence.
- Полный сценарий двух продавцов → доставка → частичная выдача → завершение → доход → вывод.
